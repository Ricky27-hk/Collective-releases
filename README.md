# Collective 下載與更新

此倉庫提供 Collective 的安裝包與版本更新檔。

## 安裝

1. 開啟 [最新版本](https://github.com/Ricky27-hk/Collective-releases/releases/latest)，下載 DMG 安裝檔。
2. 完全結束 Collective，開啟 DMG，將 Collective 拖入「應用程式」。已有舊版時選擇取代。
3. 重新開啟 Collective；如遇到系統阻擋或安裝問題，請聯絡開發人員協助。

目前提供 macOS Apple Silicon 版本。請保留原有資料與備份。

## 更新

安裝 1.1.11 或更新版本後，在「應用設定 → 應用更新」點擊「檢查更新」。如有新版，先儲存工作，再點擊「更新並重新啟動」。

檢查及下載更新不需要 GitHub 帳戶或 token。原本無法檢查更新的舊版，請先手動安裝新版 DMG 一次。

更新會驗證發布者簽章；支援時使用增量更新，必要時下載完整更新包。更新保留本機資料，請保留備份直到確認新版運作正常。
